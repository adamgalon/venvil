# Ven Vil

Field manual for Ven Vil, a Royal Paladin on Refugia (Tibia), bought on the Char Bazaar as Taktyczny Wojczek: what came with the character, gems, charms, bestiary, bosses and progress.

The whole site is one file, `index.html`, with the same layout as the Veritass page. It needs no build step: GitHub Pages serves it as is.

## Updating

Replace `index.html` with a new version and commit.
